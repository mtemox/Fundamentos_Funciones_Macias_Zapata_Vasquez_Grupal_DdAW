Laboratorio 03: Introducción a JavaScript - Desarrollo de Aplicaciones Web
Este repositorio contiene el desarrollo del Laboratorio 03, enfocado en los conceptos básicos y fundamentales de JavaScript.

📝 Descripción del Proyecto
El objetivo de este proyecto es aplicar los conocimientos iniciales de JavaScript, incluyendo la declaración de variables, el manejo de diferentes tipos de datos y la creación de funciones, en una página web simple y funcional.

JavaScript
